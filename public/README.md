# Eleições Fast

Este diretório contém a versão publicada do **Eleições Fast**, uma aplicação para consultar e acompanhar resultados eleitorais oficiais do Tribunal Superior Eleitoral (TSE).

## Como usar

Abra o arquivo `index.html` em um servidor web. A aplicação funciona inteiramente no navegador e não exige instalação.

Os resultados são consultados diretamente nas fontes oficiais do TSE. Informações e configurações salvas durante o uso ficam no armazenamento local do navegador.

## Conteúdo deste diretório

- `index.html`: ponto de entrada do site;
- `assets/`: arquivos JavaScript, CSS e outros recursos do site;
- `maps/`: dados geográficos usados no mapa eleitoral.

## Observação

Para acessar os resultados atualizados, o navegador precisa conseguir se conectar a `https://resultados.tse.jus.br`.
